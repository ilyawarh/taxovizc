# Workflow Hub

Основная долговременная память проекта — документы Git в этом репозитории. Чаты являются рабочими обсуждениями; принятые решения и измерения переносятся сюда.

- [ROADMAP.md](ROADMAP.md): приоритеты и критерии завершения.
- [DECISIONS.md](DECISIONS.md): решения и причины.
- [LOG.md](LOG.md): последовательность работы.
- [Текущий handoff](../../TAXOVIZ_HANDOFF.md): инструкция следующему агенту.
- [Архив Biomni](archive/TAXOVIZ_HANDOFF_BIOMNI_20260926.md): сохранён без правок; научные выводы не считать автоматически подтверждёнными.
- [Шаблон эксперимента](templates/EXPERIMENT.md) и [шаблон решения](templates/DECISION.md).

## Версии и ветки

Документы имеют дату и собственный статус. Исходный commit фиксирует исторический baseline; release-теги сейчас не создаются. Предложенные стадии: 0.1 — корректная воспроизводимая визуализация; 0.2 — экспериментальный корректор с baseline-бенчмарком; 0.3 — сравнение представлений и режим внешних embeddings. Номер версии не является сертификатом биологической точности.

Использовать fix/<topic>, research/<experiment-id>, feature/<topic>, docs/<topic>. Для изменений: задача с критериями → ветка → проверка → PR → ревью → слияние. Один PR отвечает за одну проверяемую цель. GitHub Issues можно подключить позже; текущий backlog уже доступен в ROADMAP, отдельная доска не обязательна.

## Вычислительный протокол

Локально: Git, VSCode/Codex, Markdown, небольшие synthetic fixtures. Удалённо: только конкретная разрешённая задача со snapshot/commit, конфигом, лимитами и выходным manifest. Вернуть компактные метрики и агрегированные результаты; полные данные остаются в разрешённом хранилище. Постоянные сервисы/организационные базы на сервере не требуются.

В этом сеансе не создавались чаты интерфейса, серверные директории проекта или установки на ноутбуке пользователя. Созданные три трека — разделы репозитория, доступные любому агенту после checkout соответствующей ветки.
