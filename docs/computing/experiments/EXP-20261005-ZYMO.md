## Executed checks and descriptive analysis

1. Verify 12 transferred run/source/support files against remote SHA-256. Workbook and reference-download hashes also recorded.
2. Parse Plotly JSON directly, without executing embedded JavaScript. Decode typed binary coordinate arrays. Assert unique read IDs, identical rank/method row sets, identical coordinates between genus/species panels, and identical IDs/metadata across versions.
3. Perform one read-only remote FASTQ scan; validate every four-line record, plus marker and sequence/quality length; compare every length to LRBinner `lengths.txt`; preserve original row positions. Zero missing plotted IDs and zero duplicate matched IDs. Global duplicates among nonmatched IDs were not tested. Extraction took about 225.5 seconds; no inference was run.
4. Load pickle with globals forbidden in the reproducible audit; verify 23 bins cover every full-read position exactly once and match `bins.txt` exactly. Join by ID and source position; plot lengths and rounded GC agree with directly measured sequences.
5. Compute label counts, read fractions and nucleotide fractions separately. K=C is equality of stored rank-specific name strings, with `unclassified` excluded, and is explicitly diagnostic evidence. No truth labels or taxonomic accuracy measures are inferred.
6. For 10,000 deterministic query reads (numpy generator seed 42), compute exact Euclidean k=15 neighborhoods in each saved 2D map using scipy cKDTree; exclude self. Report same-bin fraction, same-K=C species fraction among pairs resolved at both ends, and cross-version neighbor overlap. Metrics do not evaluate PCA-space fidelity or classifier accuracy; no threshold was tuned and no confidence intervals/test claim made.
7. Render all 290,227 points on the original coordinates, with deterministic shuffled drawing order, to inspect full-bin and K=C overlays. Inspect source gradient raster panels and generated overlays. Plot coordinates were not refitted. Small bins (<150 plotted reads) remain drawn but are not text-labelled. Two diagnostic taxon labels can overlap at nearby medians; CSVs preserve exact identities.
8. Read workbook formulas and cached values without modifying/recalculating the original. Manufacturer 16S report and workbook have identical multisets of 354 percentage values after rounding to six decimals; leading named taxa also match. This is source-provenance evidence, not proof of the physical lot.

Local analysis used an isolated ignored Python 3.11 environment; exact package list is in [analysis_environment.txt](../evidence/zymo_20261005/analysis_environment.txt). Initial parsing used the available bundled Python 3.12/pandas/numpy. CPU-only analysis; GPU not used. Peak RSS, local CPU time and total temporary disk peak were not measured. Historical log records final LRBinner resumed invocation duration 52,249.43 s, which excludes earlier preprocessing/training and failed/repeated runs; do not report it as end-to-end runtime.
