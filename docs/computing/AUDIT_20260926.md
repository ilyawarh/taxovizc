# TaxoViz: технический и методологический аудит

Дата: 2026-09-26. Проверен commit 9528b62e5da4624384c9977561a6e8caa484702a, main на момент чтения. Изучены полностью taxoviz_core.py, taxoviz_full.py, исходные ячейки notebook, README и environment.yml. Исходный handoff сохранён в Workflow Hub без изменения. Этот аудит описывает baseline, а не исправленный релиз.

## Итоговое мнение

Это полезный исследовательский прототип: общее ядро для CLI и notebook, strand-invariant признаки, отдельные adapters, кэширование taxonomy, попытка streaming и landmark projection. Но «production CLI для любого размера» и «валидированный корректор» пока не подтверждены. Корректора в коде нет. Сначала необходимо устранить нарушения контрактов данных; иначе новая модель будет обучаться на артефактах входного слоя.

Я бы сохранил визуализацию как отдельный диагностический модуль, отделил её от inference, ввёл версионированный evidence schema и начал научную разработку с простого PCA + neighbor correction. Обоснование и следующий этап — в ROADMAP и RESEARCH_BRIEF.

Headerless Centrifuger — ограничение совместимости, не доказательство потери данных в стандартном output с header. A08/A12/A13 — инженерный анализ риска, не измеренный полный performance benchmark.

GC сейчас делит G+C на всю длину, включая N. Это определённая конвенция, но для модели нужно отдельно хранить N_fraction и valid_base_length; biological GC по ACGT и долю неопределённых оснований не смешивать без обоснования.

## Что проверка не подтвердила как ошибку

В taxopy 0.14.0 атрибут taxid_lineage существует. На минимальной taxonomy fixture текущая get_rank_taxid(562,'genus') даёт 561, species даёт 562. Проверить версию на целевой машине всё равно нужно. Утверждение handoff о silent broad-except на отсутствии атрибута тоже неточно: обращение к taxid_lineage находится вне try конструктора и может выбросить AttributeError.

В установленном scikit-learn 1.8.0 короткий последний partial_fit после нормального первого batch принимается. Не объявляем это универсальным багом IPCA; первый batch и малое n требуют проверки. Numba и Python счётчики совпали на 24 строках для каждого k=4/6, включая N и короткие строки; reverse-complement invariance выдержана. Это поддерживает исправленный canonical lookup, но не является исчерпывающим тестом всех входов.

## Расхождения handoff и notebook

- Репозиторий baseline содержит 5 файлов. Старый taxoviz_analysis.ipynb, INSTRUCTIONS.md и картинки сравнения из handoff в нём отсутствуют. Новый handoff добавлен этой организационной веткой.
- Notebook содержит 17 ячеек, а не описанный набор из 15; title и README говорят о 10k. Сохранённый output загрузки — 9,993, feature matrix — 9,993×2217. Поэтому имеющееся свидетельство относится к ~10k, не к 100k. Нельзя доказать «потерю 90k при parsing» по одному handoff.
- Сохранённый output MetaPhlAn raw classified — 3,213/9,993 (32.2%). Сумма категорий с буквой M не является числом ответов MetaPhlAn: M может ответить, но проиграть K/C majority; normalization также может потерять rank. Поэтому вывод handoff «MetaPhlAn отвечает только на 17–18%» не следует из таблицы.
- Сохранённая PCA: 75 PCs, achieved variance 54.5%, requested 75%. Это не «75% дисперсии сохранено».
- Notebook CONFIG хранит t-SNE perplexity=250 и iterations=500. Описанные handoff два запуска 30/100 отдельно не доступны. Их численные сравнения сохраняем как исторически сообщённые, не как воспроизведённые.
- Категории согласования в notebook действительно совпадают с приведёнными числами handoff; это согласие двух артефактов, не верификация taxonomy относительно истины.
- Notebook outputs могут быть stale/из разных запусков; дата/порядок ячеек не заменяют run manifest. Реальные inputs и fitted models не предоставлены.

## Математические поправки

1. Для ACGT canonical vocabulary: при нечётном k число = 4^k/2; при чётном = (4^k+4^(k/2))/2. Нечётная длина не допускает self-reverse-complement palindrome. Поэтому k=3 →32, k=5 →512, k=11 →2,097,152, а не ~524k из handoff. k4=136 и k6=2080 верны.
2. Aitchison distance — Euclidean distance между CLR-векторами. Manhattan в PCA пространстве — отдельная эвристика, а не «естественная Aitchison geometry». PCA rotation сохраняет L2 при полном базисе, но не L1; truncation дополнительно теряет информацию. Нужна абляция metric/representation.
3. CLR с добавлением фиксированного count pseudocount не строго scale-invariant. Пропорции [1,0,3] и [10,0,30] дают разные CLR после +1, что воспроизведено. У коротких ридов эффект особенно велик. Subcomposition coherence нельзя приписывать неизменности всех CLR координат после удаления компонентов.
4. Два k-mer блока по 136 и 2080 измерений имеют неравный вклад; k6 блок более разрежен. Суммарный вес блоков, GC redundancy и длину нужно проверять абляциями, а не стандартизовать каждый редкий признак вслепую.
5. Повторяемость двух 2D рисунков не доказывает таксономическую чистоту. Облака одной категории agreement могут включать много организмов; расстояние между центроидами категорий не мера F1 или species separation.

## Как оценивать предложения Biomni

| Предложение | Решение аудита |
|---|---|
| HDBSCAN по UMAP/t-SNE | Сохранить как эксперимент; основной baseline — PCA/latent или graph, не обязательная 2D карта |
| Taxon enrichment clusters | Полезно; дополнить confidence/discordance и независимой truth, когда доступна |
| Weighted consensus | Высокий приоритет после починки parsers; scores и зависимости tools калибровать |
| Interactive selection/export | Полезная диагностика; сохранять точные read IDs и происхождение выборки |
| Host filtering по островам/GC | Не применять автоматически; это только гипотеза для независимой проверки |
| Simulated benchmark | Переместить в начало, до выбора сложной архитектуры |
| Landmark/streaming UMAP | Полезно, но редкие taxa могут отсутствовать в landmarks; нужен coverage/OOD audit |
| Multi-dataset embedding | После фиксации fit/transform, sample effects и базового single-sample benchmark |
| Число островов как diversity | Не использовать как валидированную ecological diversity measure |
| MKC-only reads как high-confidence truth | Согласие — кандидатный сигнал; selection bias и correlated errors не исчезают |

## Воспроизводимость этой ревизии

Скрипт: scripts/audit/reproduce_20260926.py. Выход: docs/computing/evidence/audit_20260926.json. Скрипт импортирует исходные функции, создаёт временные FASTQ/SAM/TSV/mini-taxonomy, вызывает настоящий streaming writer и не исправляет production код. Результаты и точные версии окружения записаны в JSON; это Python 3.12, не идентичная target environment Python 3.10.

Полный pipeline, t-SNE/UMAP на реальных данных, GPU, peak memory и improvement F1 не проверялись. Структуру реальной MetaPhlAn pkl, merged taxonomy и лицензии заимствуемых реализаций нужно проверять при соответствующих изменениях. Ни один алгоритмический фикс не объявлен выполненным этой веткой.
